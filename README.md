2048 Game - Java Edition
Classic 2048 puzzle game built with Java Swing. Features AI moves, undo functionality, and colorful UI.

Controls
Key	Action
Arrow Keys	Move tiles
A	Auto-move (AI chooses best move)
R	Random move
Z	Undo last move
ESC	Reset game
How to Run
bash
javac *.java
java Main
Game Rules
Merge matching tiles by moving them with arrow keys

Each merge doubles the tile value and adds to your score

Reach 2048 to win!

Game ends when no moves remain

Features
✅ Full 2048 gameplay

✅ Smart AI auto-move

✅ Undo/rollback system

✅ Score tracking

✅ Win/loss detection

✅ Color-coded tiles

Requirements
Java 8 or higher

Project Structure
Main.java - Entry point

Controller.java - Keyboard input handler

Model.java - Game logic & AI

View.java - GUI rendering

Tile.java - Tile properties

MoveEfficiency.java - Move ranking for AI
